# eduassets-site

Landing page, articles, and an integrated documentation reader for [eduAssets](https://github.com/edu-assets/app-eduassets), published at
`eduassets.tech`. The interactive system lives in a separate repository at `app.eduassets.tech`.

**Release status:** official version 1.0.1. See the [changelog](CHANGELOG.md) for the changes included in this release.

```bash
npm install
npm run dev
npm run build
```

See [docs/ENGINEERING.md](docs/ENGINEERING.md) for structure and decisions.
